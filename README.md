# PharmaNow - نظام إدارة الصيدليات

## 🚀 التشغيل

```bash
npm run dev
```

افتح: http://localhost:8080

## 🔐 تسجيل الدخول

**المدير:**
- البريد: admin@test.com
- كلمة المرور: 123456

**الصيدلي:**
- البريد: pharmacist@test.com  
- كلمة المرور: 123456

## 📱 الواجهات

- `/` - تسجيل الدخول
- `/admin` - لوحة تحكم المدير
- `/pharmacist` - لوحة تحكم الصيدلي

## ⚙️ الإعدادات

تأكد من وجود ملف `.env.local` مع إعدادات Firebase الصحيحة.

---

نظام بسيط وفعال لإدارة الصيدليات والأدوية.
