# 🔧 FCM Tokens Fix - حل مشكلة الإشعارات

## 📌 المشكلة
عند محاولة إرسال Push Notification من Admin Panel، تظهر رسالة:
```
لا توجد FCM tokens للمستخدمين المستهدفين
```

## ✅ الحل
تم إضافة طريقتين لتفعيل الإشعارات:

### 1. زر في NotificationBell 🔔
- اضغط على أيقونة الجرس في الأعلى
- ستشاهد زر "تفعيل الإشعارات"
- اضغط عليه واسمح بالإشعارات

### 2. نافذة منبثقة تلقائية
- تظهر بعد 3 ثواني من تسجيل الدخول
- اضغط "تفعيل" واسمح بالإشعارات

## 🚀 الاستخدام

### للمستخدمين:
```
1. سجل دخول
2. فعّل الإشعارات (من الجرس أو النافذة المنبثقة)
3. اسمح في المتصفح
```

### للمسؤولين:
```
1. فعّل الإشعارات أولاً (الخطوات أعلاه)
2. افتح Admin Panel → الإشعارات
3. اختر "Push (Mobile)"
4. أرسل إشعار تجريبي
```

## 📊 التحقق
افتح Firestore Console:
```
https://console.firebase.google.com/project/pharmanow-754a7/firestore
```
ابحث عن `fcmTokens` collection - عدد الـ documents = عدد المستخدمين الذين فعّلوا الإشعارات
